# 网站配图

模块配图使用 `diagrams/` 内原创 SVG 功能示意图，采用灰白底色、深色文字与蓝色连线；不含人物形象或参考站素材。侧栏与关于我使用用户提供的原始照片 `avatar.jpeg`，不作为模块示意图。

| 文件 | 示意内容 |
| --- | --- |
| `about-system.svg` | 早期产品思考图，当前不再引用 |
| `product-design.svg` | 移动端线框图汇总为产品规格文档 |
| `workflow.svg` | 原始笔记经 Skill 处理，生成两种文档 |
| `research.svg` | 任务、过程与交付证据汇总为产品研究报告 |
| `prototype.svg` | 浏览器界面与交互原型结构 |
| `knowledge.svg` | 知识文档、检索召回、模型生成与来源引用 |
| `writing-focus.svg` | 复杂工作流收束为清晰任务 |
| `writing-design.svg` | 界面结构与设计审查清单 |

所有图片都是功能或文章主题示意，不是产品截图，也不是项目完成证明。具体案例上传后，可以在 `content.js` 中替换为实际项目配图。

`golden-coast.jpg` 是旧版主题使用的 AI 生成氛围摄影，当前网站不再引用，保留以供历史版本回溯。
